# SLOOP: Spatial Language Understanding for Object Search in Partially Observed City-scale Environments (arXiv 2012.02705v3, Brown, RO-MAN 2021)

부록 포함 11쪽 전문 정독. 데이터셋·프로젝트 페이지 h2r.github.io/sloop.

## 논문 내용

**과제**: 도시 지역 2D 격자(41×41, 셀 5 m)에서 드론이 **N개 목표 물체**를 찾는다. 로봇은 **랜드마크(건물·도로) 지도를 알고**, 목표 위치는 모른다. 지도를 보고 목표 위치를 아는 사람이 "빨간 차는 Jeffrey 집 뒤, Rene 집 근처"처럼 말해 준다.
핵심 주장: **공간 언어를 확률적 관측(stochastic observation)으로 다룬다.** 언어는 목표 지정이 아니라 믿음을 갱신하는 센서다.

### 문제 정식화 (OO-POMDP, Multi-Object Search)

| 항목 | 내용 |
|---|---|
| 상태 | 목표 i 위치 s_i = (x_i, y_i), 로봇 (x, y, θ, 찾은 목표 집합 F), 지도 M |
| 행동 | MOVE(시계/반시계 45° 회전, 3셀=15 m 전진), LOOK(매 MOVE 뒤 자동), FIND(i) |
| 보상 | FIND 성공 +1000, 오답 −1000, 이동 −10. 할인 0.95 |
| 센서 | 부채꼴 45°, 깊이 3/4/5셀(15/20/25 m). **실제 영상 검출기가 아니라 정답 기반 합성 검출기** |
| 믿음 | 목표끼리 독립 b(s) = Π b_i(s_i) (목표 수에 선형). **히스토그램 믿음**(입자 고갈 방지) |
| 플래너 | POMCP(MCTS 기반 온라인 POMDP), 계획 스텝당 시뮬레이션 1000회, 최대 200스텝 |
| 전이 | OO-POMDP 그대로. 목표는 **정적** |

### 언어 → 관측 모델 (핵심)

1. 문장을 (figure, relation, ground) 튜플 집합 o_R로 파싱. spaCy 명사구·의존 구문 분석 + 동의어 코사인 유사도로 목표·랜드마크 연결. 1,650문장 중 1,521개가 튜플 1개 이상 추출됨.
2. 목표별로 독립 가정: Pr(o_R | s′) = Π_i Pr(o_Ri | s′_i, M), 그리고 Pr(o_Ri | s′_i, M) = Π_j Pr(r_j | γ_j, ψ_j, f_i, s′_i, M) (관계별 곱, 유도는 부록 A).
3. 관계 하나의 확률(식 5): **|u · v| × exp(−dist(s_i, γ)² / 2σ²)**.
   dist는 목표 후보 셀에서 랜드마크 가장 가까운 점까지 거리, u는 그쪽 단위벡터, v는 관계가 뜻하는 방향(FoR를 회전). near 같은 방향 없는 관계는 내적을 뺀다. σ는 관계 의미와 랜드마크 크기로 정한다고만 적혀 있고 **구체 값은 없다**.
4. **기준틀(Frame of Reference) 예측**: front/behind/left/right는 화자가 쓴 기준틀 ψ = (x, y, θ)가 필요하다. 원점은 랜드마크 질량중심, 각도 θ를 CNN 회귀로 예측. 입력은 랜드마크 중심으로 옮긴 28×28 회색조 지도(랜드마크·도로·주변 건물 밝기 구분, EGO-CTX). 합성곱 2단 + FC 3단(800차원 특징), 각도 차 손실 ℓ = min(|θ−θ*|, 2π−|θ−θ*|)의 제곱 평균, Adam 1e-5, 조기 종료 patience 20. front/behind 모델과 left/right 모델을 따로 학습.
5. **혼합 모델**: Pr = Σ_k w_k Pr_k. 해석을 여러 개 섞어 분포를 부드럽게 한다.
   SLOOP(m=2): 모든 관계를 near로 본 분포를 0.2로 섞음. SLOOP(m=4): FoR 관계 무시 0.25, 전부 near 0.1, 전부 at 0.05를 섞음. 가중치는 손으로 정했다.
6. 언어는 **초기 믿음 갱신 1회**로 쓰였다. 형식상 실행 중 언제든 받을 수 있다고 적혀 있지만 실험은 시작 시 1회뿐이다. 이후 LOOK 관측(합성 검출)으로 POMDP 믿음이 갱신된다.

### 데이터

- OpenStreetMap 5개 도시(Austin, Cleveland, Denver, Honolulu, Washington DC)의 40,000 m² 영역.
- 도시당 30개 배치(목표 2개씩), 배치당 AMT 작업자 최대 11명 → 1,650문장. FoR 주석 273개(front 121, behind 54, left 51, right 47).

### 결과

- **FoR 예측**(도시 단위 교차검증, 그림 5, 그림에서 읽은 근사값): front 각도 오차 Random 약 90°, EGO-CTX 약 60°, 사람 사이 불일치 약 40°. left는 맥락 없는 기준선도 비슷하게 잘 됨(left/right는 절대 기준틀인 경우가 많음).
- **종단 탐색**: 도시당 20문장 × 목표 2 = 40회, 총 200회. 목표마다 **따로** 찾는다. 기준선: MOS(keyword) — 언급된 랜드마크 위에 균일 확률(관계 무시), informed(정답 근처 작은 가우시안, 상한), uniform(하한). 자동 파싱과 수동 주석 튜플 둘 다 보고.
- 그림 7(센서 깊이 3, 200스텝 내 성공 횟수, 그림 판독 근사): informed 약 200, SLOOP(m=4) 약 190–195, MOS(keyword) 약 165–170, uniform 약 135. 수동 주석이 자동 파싱보다 높다(파싱 품질이 중요). 할인 보상 차이는 모든 센서 범위에서 SLOOP vs keyword가 통계적으로 유의.
- 관계별 할인 누적 보상(표 I, 센서 3, 수동 주석, 평균(95 % CI)) 일부:

|---|---|---|---|---|
| on | 59 | 200.65 | 267.00 | 290.05 |
| near | 35 | 97.64 | 280.69 | 249.35 |
| between | 25 | 21.48 | 172.93 | 175.59 |

- **기준틀이 틀리면 SLOOP가 keyword보다 훨씬 나빠지고(281 → −209), 혼합(m=4)이 이를 일부 회복(94)**한다. 방향 관계에서 성능이 양극화된다고 저자가 명시.
- 문장 복잡도(표 II): 관계 1/2/3개일 때 keyword 234.32 / 179.18 / 26.96, SLOOP 320.91 / 264.08 / 115.44, m=4 289.34 / 286.19 / 215.30. 관계가 많을수록 격차 확대.
- AirSim 시연: 같은 41×41 격자, 90° 회전, 집 높이 충돌 −1000. OSM으로 학습한 FoR 모델이 그대로 일반화. 정량 결과 없음.

## 논문에 없는 것

- **미지 지도**: 로봇이 랜드마크 지도를 처음부터 안다. 랜드마크가 탐사 중 나타나는 상황(우리: 문패가 아직 안 보인 방)은 다루지 않는다. 프런티어 개념 없음.
- **실내 경로형 언어**: "복도 따라가다 왼쪽 세 번째 방" 같은 순번·경로 단서, 층 정보 없음. 거리("20 m쯤") 관계도 따로 모델링하지 않는다(near/at 등 고정 σ).
- **화자 기준 방향**: 기준틀이 랜드마크 중심이다. 화자 자신의 위치·방향을 기준으로 한 "제 오른쪽"은 다루지 않는다.
- **움직이는 목표** 없음(전이 정적). 단서 나이·노화 없음.
- **여러 목표를 동시에** 찾는 종단 실험 없음(목표별 개별 시행). 개수 정보, 언급되지 않은 목표의 사전 분포 없음.
- 단서의 **신뢰도(화자 확신)** 를 입력으로 받지 않는다. 혼합 가중치는 고정값으로 손으로 정했고 학습하지 않는다. 완전히 틀린 단서(엉뚱한 랜드마크)를 실험 변수로 넣지 않았다. 나쁜 FoR 분석이 유일한 오류 실험이다.
- 탐지기는 정답 기반 합성. **mapped ≠ searched** 구분 없음.
- 플래너는 POMCP이고 이동 시간·측지 거리 기반 목표점 점수가 아니다. σ, 계획 깊이, 탐색 상수 등 세부 값이 빠져 있다. 실물 로봇 없음.

## 우리 설계에 주는 영향

1. **우리 '단서 → 확률 지도' 단계의 직접 선행 연구다. 이것은 분명히 인정해야 한다.** 언어를 관측으로 보고, 방향(내적) × 거리(가우시안)로 격자 확률을 만들어 베이즈 갱신하며, 여러 해석을 섞어 강건성을 얻는 것까지 SLOOP가 2021년에 했다. 우리 "방향 부채꼴 × 거리 고리, 확신도로 균일 분포와 혼합"은 SLOOP 식 5 + 혼합 모델의 변형이다. "언어를 확률 관측으로 다룬다"는 것을 우리 기여로 주장하면 안 된다.
2. **우리가 다른 점(기여로 쓸 수 있는 것)**:
   (a) 랜드마크를 미리 모르는 **미지 건물** — 방 단서가 문패 출현 전후로 바뀌는 2단계 표현, 프런티어 뒤 미탐사 영역에 질량을 배분하는 목표 선택.
   (b) **여러 피해자 + 단서 없는 인원**의 기대 피해자 점수(trust × 단서 질량 + 미단서 인원 × 미탐사 비율).
   (c) **움직이는 사람**의 확산(예측 단계)과 단서 나이 실험. SLOOP 전이는 정적이다.
   (d) **틀린 단서 비율**을 체계적으로 바꾼 실험과 **학습된 신뢰 가중치**. SLOOP 혼합 가중치는 손으로 정한 상수다.
   (e) 화자 기준 방향·거리·순번 같은 **실내 구조 토큰**과, 파서(VLM 2B vs 8B) 크기의 영향. SLOOP도 파싱 품질이 중요하다는 결과(자동 < 수동)가 있으니 우리 "2B는 이득의 절반을 잃는다"와 직접 대응해 인용할 수 있다.
3. **'나쁜 FoR' 결과는 우리 틀린 단서 실험과 같은 현상이다.** 방향이 틀리면 단서 없는 쪽보다 나빠지고(−209 vs 281), 혼합이 일부 회복한다. 우리 "1/3 틀리면 이득이 사라진다"를 이 결과와 나란히 놓고, 우리 신뢰도 학습이 혼합 가중치 고정보다 나은지 보이면 기여가 선명해진다.
4. **기준선으로 넣을 것**: (i) MOS(keyword) — 언급된 방/랜드마크 위 균일 확률(방향·거리 무시). 우리 시뮬에서 "room 단서만 균일" 버전으로 쉽게 재현된다. (ii) informed/uniform 상·하한 — 우리 "정확 위치 상한 62 %"와 같은 구조라 표현을 맞춘다. (iii) 가능하면 고정 가중치 혼합(m=4 방식) vs 우리 학습 신뢰도.
5. **재사용할 수 있는 수식**: 관계 확률 |u·v| · exp(−d²/2σ²)는 우리 부채꼴 × 고리 대신 부드러운 형태로 바꿔 볼 만하다(경계 효과 감소). 목표별 독립 믿음 Π b_i는 우리 다수 피해자 지도와 맞지만, 우리는 피해자 구분 없이 합산 질량을 쓰므로 그 차이를 적어 둔다.
6. **평가 표현**: "최대 스텝 대비 누적 성공 수" 곡선(그림 7)은 우리 결과 그림에도 쓸 만하다(시간 예산별 찾은 피해자 수).
