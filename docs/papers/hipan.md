# HiPAN: Hierarchical Posture-Adaptive Navigation (arXiv 2604.26504v1, KAIST, 2026-04)

7쪽 전문 정독. 코드 비공개(저자 확인).

## 논문 내용

**과제**: 알려진 목표점 g까지 이동. 지도는 학습(teacher) 때만 쓰고, 배포는 **depth + 자기 상태 + 상대 목표점**만 쓴다.
탐사(커버리지)나 목표점 선택은 다루지 않는다.

### 하위 보행 (50 Hz)

| 항목 | 값 |
|---|---|
| 명령 c | [vx, vy, ωz, 높이 h, roll θx]. 높이는 지면 기준, roll은 월드 기준 |
| 명령 범위 | vx ±1.5, vy ±1.0 m/s, ωz ±1.5 rad/s, h 0.1–0.4 m, roll ±1.0 rad |
| 커리큘럼 | grid-adaptive (Margolis): 자세가 잘 따라가지면 속도 범위 확대 |
| teacher 입력 | 고유감각 o_p = [q, q̇, **발 위치, 발 접촉**, roll·pitch, ω, 이전 행동] + c + **특권 운동 상태 [v_B, h, roll]** + **특권 도메인 [지형 높이맵 x[−2,2] y[−2,2] m, 마찰 등] → 인코더 → z_d(32)** |
| student 입력 | 고유감각 50스텝 이력 + c. 도메인 추정기(50스텝 → ẑ_d), 운동 추정기(10스텝 → x̂_m) |
| 증류 손실 | ‖a−â‖² + ‖z_d−ẑ_d‖² + ‖x_m−x̂_m‖² (DAgger) |
| 행동 | 관절 변위 Δq, PD로 q0+Δq 추종 |
| 보상 | 속도 0.4·exp(−‖err‖²/0.25), yaw 0.2, **높이 0.2·exp(−\|err\|/0.0025)**, roll 0.2·exp(−\|err\|/0.05), 행동변화 −1e-2, 부드러움 −0.1, pitch −0.5, vz²/ωxy² −0.2/−1e-3, q̇ −1e-4, q̈ −2e-7, 토크 −1e-4, 관절한계 −10, 충돌 −10 |
| 지형 | 계단, 구멍, 경사, 평지 |
| 무작위화(학습/시험) | 탑재물 0–3 / 0–5 kg, CoM ±0.1 / ±0.15 m, 마찰 0.7–1.2 / 0.4–1.5, 반발 0–0.1 / 0–0.3, 모터 토크 배율 0.9–1.1 / 0.8–1.3, 10초마다 충격 |
| 학습량 | teacher 4,096대 12시간, student 300대 2시간 (RTX 4090) |

### 상위 항법 (10 Hz)

| 항목 | 값 |
|---|---|
| 동역학 | **하위 student를 상위 환경 안에 넣고** 학습 (추종 오차·지연 반영) |
| teacher 입력 | 특권 지도 [3D 점유 14×11×11 + 2.5D 고도 31×21, 0.1 m] → 인코더 → z_s(32), 상위 고유감각 [o_p, c_{t−1}], 특권 운동 상태, 상대 하위목표 |
| student 입력 | depth 180×320 (전방 카메라) → **GRU 포함 추정기** → ẑ_s, 상위 고유감각, 추정 운동 상태 x̂_m, 상대 목표 |
| 증류 손실 | ‖c−ĉ‖² + ‖z_s−ẑ_s‖² (DAgger) |
| 보상 | 도착 5.0(0.1 m), **상태 방문 횟수 0.5/√η**, 목표 속도 0.25·exp(−\|v_des−‖v‖\|/0.3) (v_des 0.3–1.2), 명령 변화 −0.1, 명령 부드러움 −0.1, 추종 오차 −0.2, 몸 속도 −0.1, 기본 자세 −4e-2, 명령 한계 −2.5, 충돌 −2.5 |
| PGCL | 특권 전역 경로(GVD 위 A*)에 d m 간격 하위목표. d=1 m에서 시작, 전부 도달하면 d += 1 m, d > 경로 길이면 최종 목표만. 최종 단계를 꾸준히 성공하면 새 시작·목표 |
| 환경 | WFC 타일(평지·거친 면·막힌 면) + 벽·탁자·공중 상자 무작위. 20×20 m 6종 |
| depth 증강 | 무작위 지우기, 가우시안 블러, 노이즈, 카메라 위치 ±5 cm·pitch ±2.5°, 4 m 자르기 → [0, 1] |
| 학습량 | teacher 1,024대 18시간, student 128대 6시간 |

### 결과

- 시뮬(환경당 300과제 × 10시드, 5–30 m): 성공률 Corridor 98.5, Room 98.4, Complex 94.4 / 94.7 %.
- 자세 조절 없음: Complex 74.2 / 73.1 %. PGCL 없음: 78.1 / 74.5 %. IR 없음: 90.8 / 90.7 %. 둘 다 없음: 약 50 %.
- 한 정책이 걷기와 항법을 모두 하는 Flat-RL: 43–45 % (복잡 환경).
- 실물: Go1 + D435i + Intel NUC, ROS. depth는 자르기·정규화·**구멍 메우기 필터**. 최장 64.9 m, 막다른 길 되돌아가기, 조명 변화, 실외.
- 한계: 유리·반사면은 depth로 안 보여 통과 가능 공간으로 오인. 향후 과제로 **표지판 같은 의미 정보** 사용을 든다.

## 논문에 없는 것 (직접 정해야 함)

- 네트워크 크기, PPO 하이퍼파라미터, DAgger β 스케줄, GRU 크기
- 상태 방문 횟수를 세는 격자 크기
- GVD와 경로 계산의 세부 사항, 하위목표 성공 판정 횟수("꾸준히")
- 목표점이 **도중에 바뀌는** 경우와 목표가 **도달 불가하거나 미지 영역**에 있는 경우. 논문은 충돌 없는 위치의 고정 목표만 쓴다.
- 커버리지, 지도 구축, 텍스트 정보: 전혀 다루지 않음

## 우리 설계에 주는 영향

1. **하위 teacher가 지형을 못 본다 (현재 우리 구현의 결함).** HiPAN teacher는 지형 높이맵과 발 위치·접촉을 특권 정보로 받는다. 우리 teacher는 blind라서, 문턱에서 발을 끌거나 멈춘 현상(3–5단계)과 관련이 있을 수 있다. → 높이맵·발 정보를 teacher에 넣고, student가 **도메인 잠재 z_d와 운동 상태**까지 추정하게 바꾼다(현재는 속도만 추정).
2. **roll 명령이 없다.** 우리 하위 정책은 높이만 학습했고 pitch·roll은 0으로 고정했다. 명령은 HiPAN처럼 [vx, vy, ωz, h, roll]로 맞춘다.
3. **높이 추종 보상**: HiPAN은 exp(−|e|/0.0025)로 매우 날카롭다. 우리는 exp(−e²/0.05²).
4. **상위 학습은 하위 student를 넣고 한다.** 하위 student를 먼저 확정해야 상위 학습을 시작할 수 있다. 제어 지연도 이 단계에서 반영된다.
5. **카메라**: HiPAN D435i는 기울기 0°, 높이 0.12 m. 우리 D435i는 약 13° 아래로 기울어 있고 위치가 (0.32, 0, 0.055)다. 시야가 달라 그대로 옮길 수 없다.
6. **우리 확장 지점**: (a) 목표점이 커버리지·텍스트로 계속 바뀌므로 student가 목표 전환과 미지 영역 목표를 다뤄야 한다. (b) 라이다 3D 지도·궤적은 목표점 선택에 쓴다. (c) 학습형 가중치는 HiPAN에 대응 부분이 없다.
7. **학습 예산**: 논문은 4090 기준 하위 14시간, 상위 24시간. 우리 3090으로는 1.5배 이상 걸린다고 본다(추정).
